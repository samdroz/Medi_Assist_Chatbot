# MediAssist AI

## Overview

MediAssist AI is a modern, production-quality medical chatbot built using Python Flask and Vanilla JavaScript. It provides instant keyword-based responses to over 100 medical queries spanning symptoms, diseases, nutrition, mental health, and first aid.

## Features

### 1. Extensive Medical Knowledge Base

* 100+ medical responses
* Covers symptoms, diseases, nutrition, mental health, and first aid

### 2. Modern User Interface

* ChatGPT-inspired premium design
* Glassmorphism effects
* Inter typography

### 3. Emergency Detection

* Real-time detection of life-threatening keywords
* Immediate warning alerts for emergency situations

### 4. Dark Mode Support

* Fully implemented light and dark themes
* Persistent user preference storage

### 5. Chat History

* LocalStorage-powered history sidebar
* Easy access to previous conversations

### 6. Typing Simulation

* Realistic bot typing animations
* Enhanced user experience

### 7. Responsive Design

* Optimized for mobile, tablet, and desktop devices

## Technology Stack

### Backend

* Python 3.12
* Flask

### Frontend

* HTML5
* CSS3 (Variables, Flexbox)
* Vanilla JavaScript

### Additional Libraries

* FontAwesome 6 (Icons)

## Installation and Usage

### Step 1: Clone the Repository

Clone the project repository to your local machine.

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Run the Application

```bash
python app.py
```

### Step 4: Access the Application

Open your browser and navigate to:

http://127.0.0.1:5000
